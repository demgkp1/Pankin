# Pankin 0.3.1

Linux 运行时修复版本，适用于 Ubuntu 24.04 / Linux x86_64。

## 新增
- 启动器支持发现没有 `.desktop` 文件的可执行 AppImage，扫描 `~/app`、`~/Applications`、`~/AppImages`、下载目录和 `~/.local/bin`。
- 发布包增加 `SHA256SUMS.txt`，用于校验 AppImage 与 deb 安装包。

## 改进
- 文本剪贴板历史接入 Avalonia 原生剪贴板，不再依赖安装 `xclip` 或 `wl-clipboard`。
- AppImage 直接执行，不通过 shell 解释文件名；已登记的应用去重并保留 `.desktop` 元数据。
- 改进打包脚本，优先使用缓存的 AppImage runtime，并补齐 AppDir 图标。

## 修复
- 修复 AppImage 自启动文件格式及持久路径处理；使用 `--autostart` 登录后仅后台常驻，不自动弹出面板。
- 修复启动器和剪贴板窗口内点击被误判为外部点击的问题，兼容高 DPI；Wayland 下避免使用不可靠的 X11 全局坐标。
- 修复文本剪贴板内容无法采集和显示的问题，记录启动时已有文本及后续复制内容。
- 串行化原生剪贴板读写，避免后台监听与显式读取互相干扰。
- GNOME Wayland 后台划词采样不再调用可能抢焦点的 `wl-paste` 回退。
- 同步程序集、设置页、更新检查器和打包版本号为 0.3.1。

## 更新方式
1. 从托盘退出正在运行的旧版 Pankin，避免两个实例同时响应快捷键。
2. AppImage 用户：下载 `Pankin-0.3.1-x86_64.AppImage`，放到固定目录并赋予执行权限，再手动启动一次。原来已启用的自启动项会更新到新文件路径；确认成功后再删除旧文件。
3. deb 用户：安装 `pankin_0.3.1_amd64.deb`，再启动 Pankin。
4. 下载两个安装包及 `SHA256SUMS.txt` 后，可在同一目录运行 `sha256sum -c SHA256SUMS.txt` 检查完整性。

## 验证与已知限制
- 修复代码通过全部 388 项单元测试；100% 和 200% 缩放下各 14 项隔离原生窗口回归验证通过。
- 新包发布前执行自包含打包及 AppImage 后台启动冒烟检查。
- 实际重启后的自启动及真实 GNOME Wayland 会话仍需人工确认。
- 本版本修复文本历史链路，不新增图片/文件剪贴板采集，也不能补回此前未记录的历史。
