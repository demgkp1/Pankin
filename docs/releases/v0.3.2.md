# Pankin 0.3.2

Linux 失焦自动隐藏修复版本，适用于 Ubuntu 24.04 / Linux x86_64。

## 改进
- 启动器、剪贴板和超级面板统一使用可取消的 120 毫秒失焦检查；重新激活、隐藏或关闭窗口时取消旧检查，避免旧回调误关闭新打开的面板。
- 右键菜单及所属弹出窗口纳入面板的屏幕范围判断，避免菜单区域被误判为外部点击。
- 同步程序集、设置页、更新检查器和 AppImage/deb 打包版本为 0.3.2。
- 发布附件包含 `SHA256SUMS.txt`，用于校验两个安装包。

## 修复
- 修复鼠标仍停留在面板上时，切换到其他应用后不自动隐藏的问题；鼠标悬停不再阻止真正的失焦隐藏。
- 修复打开面板后 180 毫秒内的失焦事件被直接忽略的问题。
- 修复延迟隐藏检查无法在临时重新激活后可靠取消的问题。
- 启动器窗口位置在确认需要隐藏时再保存，避免临时焦点切换提前触发保存。
- 保留“失焦自动隐藏”开关：关闭后面板不会因失焦隐藏，重新开启后恢复工作。

## 更新方式
1. 从托盘退出正在运行的旧版 Pankin，避免两个实例同时响应快捷键。
2. AppImage 用户：下载 `Pankin-0.3.2-x86_64.AppImage`，放到固定目录，赋予执行权限后启动。启用自启动的用户需手动启动新版一次以刷新路径。
3. deb 用户：安装 `pankin_0.3.2_amd64.deb` 后启动 Pankin。
4. 两个安装包和 `SHA256SUMS.txt` 放在同一目录，可运行 `sha256sum -c SHA256SUMS.txt` 校验。

## 验证与已知限制
- 全部 388 项单元测试通过，构建 0 警告 / 0 错误。
- 原生隔离窗口回归在实际 100% / 200% 缩放下各 33 项通过；禁用全局坐标的 Wayland 安全分支在两种缩放下各 34 项通过。覆盖真实焦点转移、鼠标未移动、快速失焦、重新激活、设置开关、面板内部点击和右键菜单。
- 实际 AppImage 已通过鼠标未移动时的失焦隐藏、面板隐藏后后台常驻及持久自启动路径冒烟检查。
- Wayland 安全分支验证仍运行于隔离 X server，不等于真实 GNOME Wayland 会话的端到端测试；实际会话及重启自启动仍需人工确认。
- 不修改或覆盖已发布的 0.3.1 标签及 Release。
